# 演示样例详解

> 技能整体介绍与安装使用见仓库根目录的 [`README.md`](../README.md)；
> 这里是两套样例的**配置、实测数据与文案样张**详解。

两套**开箱即跑**的完整配置，分别代表「清冷内向」与「豪迈外向」两种典型宣传诉求。

| 文件 | 说明 |
|---|---|
| `01-jiangxue-ink.poem.json` | 《江雪》水墨孤高 · 80s 冷启动款 |
| `02-lushan-realistic.poem.json` | 《望庐山瀑布》电影写实 · 71.6s 宣传款 |
| `02-lushan-realistic.expected-copy.md` | 样例二**真实生成的**发布文案全文（未润色） |

## 怎么用

推荐**复制到自己项目目录**再跑（避免产物写回技能目录）：

```bash
# <py> = 托管 venv 解释器，<SKILL> = 本技能目录
mkdir -p ~/my-poem && cd ~/my-poem
cp <SKILL>/examples/02-lushan-realistic.poem.json ./poem.json

<py> <SKILL>/scripts/poem2video.py --config poem.json --stage prompts
#   → 按 images/prompts.md 用 ImageGen 逐条生图，存为 images/NN-<诗句>.png

MIMO_API_KEY=... <py> <SKILL>/scripts/poem2video.py --config poem.json --stage tts
<py> <SKILL>/scripts/poem2video.py --config poem.json --stage build   # 或 --stage all 连质检一起
```

产物在 `<项目目录>/poem2video_out/`。想改成自己的诗：只动 `poem` / `style` / `voice` 三段。

## 样例一 ·《江雪》水墨孤高

> 千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。 —— 唐·柳宗元

- **组合**：`ink` 水墨国画 + `baihua` 白桦（苍老男声）+ `guqin` 古琴
- **定位**：深夜情绪向、国学账号冷启动；主打「孤独」「清冷」「治愈」标签
- **节奏**：舒缓，约 80 秒（四句五言）

| 转场帧差峰值 | 3.3 / 255 | ✅ 柔和叠化 |

**结构**：宣纸底竖题「江雪·唐·柳宗元·五言绝句」+ 朱印 → 四句各配一幅水墨长卷
（横排字幕压在底部压暗条上）→ 片尾逐句复诵全诗 → 作者信息卡。

## 样例二 ·《望庐山瀑布》电影级写实（宣传向）

> 日照香炉生紫烟，遥看瀑布挂前川。飞流直下三千尺，疑是银河落九天。 —— 唐·李白

- **组合**：`realistic` 电影写实 + `suda` 苏打（清朗男声）+ `guzheng` 筝
- **定位**：品牌/账号宣传、文旅向；主打「豪迈」「气势」「壮阔」标签
- **节奏**：紧凑，71.6 秒（四句七言）

## 两个样例的差异一览

| 维度 | 江雪（样例一） | 望庐山瀑布（样例二） |
|---|---|---|
| 情绪 | 孤高清冷 | 雄浑豪放 |
| 画风 | 水墨留白、宣纸质感 | 电影写实、体积光 |
| 音色 | 白桦（苍老男声） | 苏打（清朗男声） |
| 配乐 | 古琴（清冷） | 筝（明亮） |
| 节奏 | 舒缓 80s | 紧凑 71.6s |
| 适合平台 | 深夜情绪流、国学号 | 品牌宣传、文旅号 |

> 文案结尾句会随 `poem.theme` 变化（如「孤高清冷」→「像把心放进了一场雪里」，
> 「雄浑豪放」→「像胸中过了一场山河」），不会串味。
