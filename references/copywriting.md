# 发布文案（抖音 / 小红书）

`--stage copy` 会按配置自动产出 `<题名>·发布文案.md`，含两个平台各一套。
**脚本给的是结构化初稿**——事实（题名、朝代、作者、时长、画风、音色）由数据驱动不会写错，
**措辞层面你应当再润色一遍**，让钩子更锋利、更像人话。

## 两个平台的差别

| | 抖音 | 小红书 |
|---|---|---|
| 标题 | 首行即标题，15–25 字，超长会被折叠 | 独立标题，≤20 字最佳，可用 1 个 emoji |
| 正文 | 前 3 行是黄金钩子，其余可长 | 笔记体、短句分行、多留空行 |
| 话题 | 6–8 个（3 精准 + 2 情绪 + 2–3 风格/热词） | 10 个以内 |
| 封面 | 一帧画面 + 大字 | 首图 + 四联画拼图 + 作者卡 |
| 语气 | 直给、有观点、留钩子 | 分享感、过程感、"我花了好几天" |
| 时长偏好 | 完播率重要，**前 3 秒必须抓人** | 可稍长，重"收藏价值" |

## 标题钩子公式（任选其一，套到具体诗上）

1. **数字 + 断言**：`{N}个字，写尽{theme}｜《{题}》{画风}`
2. **原句 + 反差**：`{首句}，{次句}——我把它画成了一部{画风}短片`
3. **时长承诺**：`用{时长}秒，把《{题}》画给你看`
4. **作者代入**：`{朝代}{作者}写下的{theme}，全在{首句}`
5. **提问钩子**：`你有多久没有完整读完一首诗了？｜《{题}》`
6. **极值断言**：`全网最{theme}的{N}个字，读一遍，静一遍`

> 避免的写法：空洞抒情（"太美了""绝美"）、纯复述诗句、把诗名藏在最后。
> **数字（字数/秒数）+ 具体情绪词**是中文诗词类内容最稳定的钩子组合。

## 正文结构

```
① 引诗（原句，带标点，独立成段）
② 一句断言/概括（N个字，一场XX，一个人）
③ 作者的处境与心境（为什么写这首诗——比复述诗意更抓人）
④ 这一版做了什么（每句一画 / 音色 / 配乐 / 时长 / 片尾彩蛋）
⑤ 情绪收束句（听完整首，给自己留一点安静的时间）
⑥ 互动引导（你最喜欢哪一句？）
```

第 ③ 步是差异化的关键：**讲"人"比讲"诗"更容易出圈**。例如《江雪》写柳宗元被贬永州，
而不是解释"千山鸟飞绝是什么意思"。

## 话题标签策略

```
精准流量（必带 3 个）：#<诗名> #<作者> #<朝代>诗 / #古诗词
情绪扩流（2 个）：按 theme 取，如 #孤独 #治愈 #田园生活 #思念
风格与热词（2–3 个）：#<画风名> #中国风 #东方美学 #以诗入画 #传统文化
```

**不要堆标签**：超过 8 个（小红书 10 个）会稀释权重。宁可少而准。

## 封面

- 取**最有辨识度的那一帧**（通常是最后一句的画面，主体最完整）。
- 大字 2–5 字最抓眼，优先直接用诗句末句；小字补一句解释或悬念。
- 大字压在画面**下三分之一**，避开人脸/主体。
- 小红书首图建议左上角加小字标签，形成个人视觉识别。

## 发布小贴士（写进文案末尾给用户）

- **黄金 3 秒**：开头直接用首句旁白 + 全屏画面，不要留白开场、不要长片头。
- **发布时间**：静品类内容 21:00–23:00 或 06:30–08:00。
- **评论区置顶**：把末句单独发一条，问一个二选一的问题（"是孤独还是自由？"）
  ——二选一比开放式提问更容易起量。
- **系列化**：第二首沿用同一画风与音色，主页形成「以诗入画」合集，涨粉更稳。
- **emoji 取舍**：账号偏素雅就一个都别加；偏活泼在首尾各加 1–2 个
  （❄️🌨️🌙 之类与意象相关的，而不是随手加）。
