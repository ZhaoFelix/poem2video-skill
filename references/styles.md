# 画风库（8 种）

配置项 `style` 填风格 ID。风格同时决定**生图画风**与**成片排版**（底色/文字色/印章色/
字幕压暗强度/字体族），所以换风格不用改任何脚本。

## 选择指南

| ID | 名称 | 气质 | 最适合的诗 | 默认音色搭配 |
|---|---|---|---|---|
| `ink` | 水墨国画 | 极简、典雅、留白 | 孤寂、清冷、禅意（《江雪》《鹿柴》） | 白桦 |
| `qinglv` | 青绿山水 | 华贵、古意、层叠 | 山水壮游、春景（《望庐山瀑布》《早春》） | 苏打 |
| `gongbi` | 工笔重彩 | 精致、富丽、细腻 | 花鸟、庭院、闺情（《春江花月夜》） | 茉莉 |
| `realistic` | 电影级写实 | 大气、真实、有冲击力 | 边塞、大漠、夜泊（《使至塞上》《枫桥夜泊》） | 白桦 |
| `illustration` | 唯美插画 | 清新、通透、海报感 | 社媒向、轻快题材（《村居》《咏柳》） | 苏打 / 冰糖 |
| `moonlight` | 月下水墨 | 冷调、幽静、银白 | 夜景、思乡、怀人（《静夜思》《水调歌头》） | 茉莉 |
| `papercut` | 剪纸木版 | 民俗、热烈、装饰 | 节庆、童趣（《元日》《村晚》） | 冰糖 |
| `dunhuang` | 敦煌壁画 | 厚重、苍茫、矿物质 | 边塞、佛理、历史（《凉州词》《出塞》） | 白桦 |

## 生图要点（对每种风格都适用）

1. **一句一图**：`--stage prompts` 会为每句诗生成一条完整提示词，逐条调用生图，
   **不要**一次让它生成四格拼图（拼图会被裁切搞坏）。
2. **主体居中**：成片是 16:9 居中裁切铺满全屏。生成 3:2 画面时，让主体（人、舟、
   建筑）落在画面中部的安全区，不要贴着边缘。
3. **画面里不要有文字**：提示词已带此约束，但仍要目检；一旦图上有题字/印章，
   会和成片字幕打架（也更容易带水印）。
4. **风格一致性**：同一首诗的 N 张图必须同一画风。生成时保持提示词前缀完全一致，
   只改「主题 / 画面内容」部分。
5. 不满意就**单独重生成那一张**，不要重做全部。

## 各风格的生图侧重

- **ink**：强调墨色浓淡与大面积留白；颜色只允许黑白灰加极少淡赭。留白是它的一半。
- **qinglv**：石青石绿要"矿物颗粒感"，赭石勾轮廓，泥金点云气；色彩要重但不能脏。
- **gongbi**：勾线要细而挺，设色层层渲染；主体轮廓清晰，背景淡彩平涂留层次。
- **realistic**：真实光影与材质，浅景深 + 体积光，暗部保留细节；色调统一克制。
- **illustration**：柔和通透的渐变，形体简洁优雅，干净有设计感；拒绝厚涂与写实。
- **moonlight**：整体冷调偏蓝紫，月光处提亮成柔光晕，水面有微弱反光。
- **papercut**：平面化 + 粗轮廓 + 高饱和平涂，剪纸镂空的装饰纹样，构图饱满匀称。
- **dunhuang**：土红赭石石青石绿，泥金勾线，墙面斑驳剥落的肌理，造型古拙饱满。

## 渲染侧的连带效果（了解即可，不用手改）

风格里的 `palette` / `caption` / `card` 决定成片观感：
- **字幕可读性**：深色系风格（realistic/moonlight/papercut）用更强的底部压暗；
  亮色系（illustration/qinglv）用带描边的白字。
- **文字卡**：用最后一张画作虚化 + 罩层做底，保证深色正文可读。
- **字体族**：水墨/青绿/工笔/敦煌用宋体（`songti`），写实/插画用黑体类
  （`hiragino`，机内降级到 Songti）。想换字体改 `styles.json` 的 `font.family`。

## 自定义新风格

在 `assets/styles.json` 追加一项即可（脚本自动识别）。最少需要：
`name / desc / image_prefix / image_suffix / size / palette / font / caption / card`。
照着 `ink` 抄一份改配色最省事。加完在 `references/styles.md` 补一行说明。
