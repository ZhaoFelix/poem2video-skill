## 三种模型

| 模型 | 能力 | 何时用 |
|---|---|---|
| `mimo-v2.5-tts` | 预置音色（上表） | **默认**。要稳定、要好听 |
| `mimo-v2.5-tts-voicedesign` | 用自然语言凭空设计音色 | 想要"专属声线"（如七旬说书人） |
| `mimo-v2.5-tts-voiceclone` | 传音频样本复刻音色 | 想用某个真人/自有音色 |

`voicedesign` 用法：`narration.model` 改成它，`narration.voice_design_prompt` 写描述，
`voice` 字段会被忽略。文件里预置了四个模板（`elder_scholar` / `young_scholar` /
`lady_guqin` / `storyteller`）。

写法要点（官方建议）：1–4 句，涵盖**性别年龄 / 音色质感 / 情绪语气 / 语速节奏**；
不要写混响、EQ、压缩等后期词；不要写自相矛盾的特征。

## 导演模式（提升演绎感的关键）

接口是 OpenAI 兼容的 chat 格式，关键约定：

- `role: user` → **风格/导演指令**（不朗读）
- `role: assistant` → **待朗读文本**（读这段）
- 文本写错角色会**不出声**

脚本按【角色】【场景】【指导】三段式自动组装：

```
【角色】你是一位年逾七旬的古典诗文朗诵大家，嗓音苍劲醇厚、略带沙哑的磁性，气息深远绵长。
【场景】正在录制《江雪》（柳宗元）的诗画影片旁白。画面对应第一句，气息放空，像对着茫茫天地自语。
【指导】语速极缓，字字沉稳清晰、咬字有金石质感；句尾留出悠长空白，不要抢拍。情绪孤高清冷、静中带傲骨，绝不悲啼煽情。
```

想更细可自己写进 `director.by_mood`，维度：语速与顿挫 / 气声与实声 / 咬字肌理 /
共鸣位置 / 情绪起伏。

## 标签速查

**风格标签**（放 `assistant` 文本开头，格式 `(标签1 标签2)诗句`，括号 `()`/`（）`/`[]` 均可）

- 基础情绪：开心 悲伤 愤怒 恐惧 惊讶 兴奋 委屈 平静 冷漠
- 复合情绪：怅然 欣慰 无奈 愧疚 释然 嫉妒 厌倦 忐忑 动情
- 整体语调：温柔 高冷 活泼 严肃 慵懒 俏皮 深沉 干练 凌厉
- 音色定位：磁性 醇厚 清亮 空灵 稚嫩 苍老 甜美 沙哑 醇雅
- 人设腔调：夹子音 御姐音 正太音 大叔音 台湾腔
- 方言：东北话 四川话 河南话 粤语　　唱歌：`(唱歌)歌词`

**音频标签**（可插在文本任意位置，细粒度控制）

- 语速节奏：吸气 深呼吸 叹气 长叹一口气 喘息 屏息
- 情绪状态：紧张 害怕 激动 疲惫 委屈 撒娇 心虚 震惊 不耐烦
- 语音特征：颤抖 声音颤抖 变调 破音 鼻音 气声 沙哑
- 哭笑表达：笑 轻笑 大笑 冷笑 抽泣 呜咽 哽咽 嚎啕大哭

**实用组合**：`(孤高 深沉)独钓寒江雪。` / `(叹气)千山鸟飞绝。` /
`(气声)孤舟蓑笠翁。` / `独钓(停顿)寒江雪。`

## 注意

- 合成文本必须放 `assistant`，放 `user` 会不出声。
- 返回 24kHz 单声道 WAV（base64）。整体质量干净（无削波、12kHz 以上能量 0%）。
- 该模型**语速明显慢于常规 TTS**（五言一句 4–6.5 秒），这正是古诗词朗诵想要的，
  但会让成片变长——时间轴会自动适配，不用手调。
- 密钥：环境变量 `MIMO_API_KEY` 或 `~/.workbuddy/mimo_api_key`；**不要提交到任何文件**。
